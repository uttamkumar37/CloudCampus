# E2E Test Guide

## Suggested E2E Flows
- Login as school admin, create academic setup, admit student, mark attendance.
- Create fee structure, assign fee, collect/verify payment path.
- Create exam, enter marks, publish/read result.
- Teacher homework assignment and student submission.
- Parent child dashboard read-only flow.
- Public website publish and public route render.

## Rules
- Seed data must be synthetic.
- E2E tests must not depend on external paid providers unless mocked/sandboxed.
